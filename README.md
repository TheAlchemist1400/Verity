# Verity - Website Project (Part 2)

## Project Overview

## Description:
This document reflects the continuation and completion of the Verity Clothing Brand website, focusing on building a working prototype from the Part 1 proposal and research. In Part 2, the project moved from concept and planning into development, using HTML and CSS to create a site. The website highlights who is Verity’s, their previous work, mission, showcases apparel category, and provides interactive elements that support engagement with the target audience.

## Implementation Summary
The website was created with a mobile-first design approach, ensuring accessibility and performance across devices. It uses semantic HTML for structure, CSS (including responsive media queries) for design and layout.

The following pages and features were successfully implemented:

### Home Page :
Hero section with brand introduction and background image styling. A navbar responsive to different screens and clean layout.

### About Page :
Storytelling section about the Verity brand, its roots in the Vaal, and its cultural inspiration. Includes text and supporting imagery.

### Shop Page :
Visual product catalogue with grid layout for different categories (jackets, shirts, pants, sweaters). Items styled with hover effects for a professional.

### Koto :
Gallery section for photoshoots

### Enquiry :
Contact form for wholesale enquiries and event sign-ups.

## Key Features Completed in Part 2

Responsive navigation bar with toggle menu on smaller screens.

Hero section redesigned to support image backgrounds.

Grid & Flexbox layouts for product catalogue.

Integrated Font Awesome icons for social links.

Styling built with a defined design system (custom properties for colors, fonts, spacing, and border radii).

Transparent image handling in product listings, ensuring text overlays remain clean and accessible.

Content structure and styling refinements (brand colors from Coolors palette, typography hierarchy).

Challenges & Solutions

Transparent PNGs created extra empty space under images: Solved by overlaying text with CSS positioning and trimming padding.

Spacing issues in shop grid: Initially caused by incorrect HTML structure and flexbox math, resolved by correcting <ul> nesting and switching to a grid layout.

## Reflection

Through Part 2, I gained practical experience in responsive design, semantic HTML, custom CSS variables, flex/grid layouts. I also learned the importance of clean image assets and proper HTML structure. The website is now functional, visually aligned with the Verity brand, and structured in a way that can later integrate into an e-commerce site that will sell verity clothing.
